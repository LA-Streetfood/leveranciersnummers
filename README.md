# LA Streetfood leverancierspagina

Deze map is klaar voor GitHub Pages.

- `index.html` is de pagina.
- `logos/` bevat de logo-afbeeldingen.
- Houd de mapstructuur exact zo.

## GitHub Pages
Upload `index.html` en de map `logos` naar de root van je repository. Zet daarna GitHub Pages aan via Settings > Pages en kies de branch waarop deze bestanden staan.
